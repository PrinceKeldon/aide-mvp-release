Vera is a local-first personal agent for your day.

What is in the MVP

One memory, one approval fabric, many trusted devices.

Your Day

A prepared operating view for calendar, unread email, pending approvals, and tasks.

Email and approvals

Read, search, draft, and send with approval gates on sensitive outbound actions.

Owner Mesh

Pair trusted devices, inspect trust, route approvals, and test delegated work.

M-Peer foundations

Early sovereign peer collaboration model: another person's AIDE is not your device.

Model routing

Run local-first with Ollama, or route selected work to Groq, Gemini, or OpenAI.

FinanceOS opt-in

Local finance tooling is available as an optional module, not the default MVP surface.

Privacy and control

Your agent should not require surrendering your day.

Vera is designed around owner control: local storage, explicit model keys, approval tiers, trusted device pairing, and revocable mesh trust. Telegram is optional but strongly recommended as a mobile owner console for approvals and delegated node work.

First-run notes

If macOS blocks the app, open it intentionally.

Unidentified developer

This MVP build may not be notarized. If macOS blocks it, open System Settings, allow the app, then launch Vera again.

Local URL

Vera runs locally at http://localhost:3000. If setup does not open automatically, paste that address into your browser.

Logs

Runtime logs live at ~/.aide/data/aide.log. They are useful when checking model, mesh, email, or calendar setup.
